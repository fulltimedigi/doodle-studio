🎞️ ريل مركّب

اكتب الموضوع، والأداة تكتب الخطّاف والمشاهد والتعليق الصوتي — ثم تركّب الفيديو جاهزًا للرفع: 1080×1920 مع غلاف 4:5 وملف ترجمة.

هذه الأداة تحتاج تشغيل الاستوديو على جهازك أو على خادم.
تركيب الفيديو يتم بمتصفح وffmpeg، وهذا لا يعمل داخل صفحة ساكنة. شغّله مرة واحدة:
npm install && npm run setup && npm start
ثم افتح http://localhost:7860/web/reel.html. الكتابة أدناه تعمل هنا على أي حال، ويمكنك نسخ الـ JSON وتشغيله بـ doodle reel.
