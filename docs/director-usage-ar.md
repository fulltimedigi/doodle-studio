# تشغيل Director V3 واستخدامه

يتطلب التشغيل المحلي Node.js 20 أو أحدث وChromium. يتطلب فحص التصدير أيضًا FFmpeg وFFprobe مع H.264 وAAC.

```bash
npm ci
npm run setup
npm start
```

افتح `http://localhost:7860/web/director-v3.html` أو استخدم المنفذ الذي يطبعه الخادم. إذا كنت تستخدم Chromium مثبتًا محليًا، حدد `CHROMIUM_PATH` لأوامر Director و`CHROME_PATH` لمجموعة الاختبارات. استخدم `PORT` لتحديد منفذ الخادم عند الحاجة.

1. من بطاقة «المشروع»، اختر المقاس ثم استورد `examples/fulltimedigi-first-ad.json` من «استيراد سيناريو دون وسائط». يتضمن المشروع ستة مشاهد في 54 ثانية.
2. راجع النصوص والتوجيه والتوقيت حسب [دليل الإعلان](fulltimedigi-first-ad.md). عدّل مدة المشهد ونصه من لوحة المشهد، ثم طبّق التعديلات.
3. أرفق تسجيلات التطبيق الفعلية للمشاهد المحددة. أرفق صورة أو فيديو توضيحيًا للمشاهد البصرية حسب المخطط. يمكن إنتاج الوسائط خارج الأداة وإرفاقها محليًا.
4. أرفق تعليقًا صوتيًا مرخصًا وأي موسيقى مرخصة ترغب في استخدامها. اضبط مستوى الموسيقى وخفضها أثناء التعليق، وراجع التوقيت والترجمة بالمعاينة.
5. احفظ نسخة `.ftdproject` للاحتفاظ بالوسائط وإعدادات المزيج. اختر «فتح مشروع كامل» للاسترجاع. ملف JSON يحفظ السيناريو. احتفظ بالصورة المرجعية للشخصية منفصلة لإرفاقها عند الحاجة.
6. استخدم قائمة الجودة قبل التصدير. يبقى المشروع مسودة إذا كانت وسائطه أو أدلته أو صوته المطلوب ناقصًا. راجع لقطة البداية والنهاية وكل نص قصير على المقاس المستهدف.

للتصدير المحلي الحتمي إلى MP4 بعد اكتمال المشروع، استخدم ملف الحزمة الكامل ومسار إخراج جديد.

```bash
node scripts/render-director.mjs project.ftdproject output/final.mp4 --fps 30 --size 1080
```

استخدم `--fps 24` عند الحاجة. يحدد مقاس المشروع اتجاه التصدير. يمكن استخدام `--draft` لمعاينة اختبارية. اختر اسم ملف يوضح أنه مسودة. يعتمد تنسيق التصدير داخل المتصفح على قدرة الترميز لديه.

يمكن تشغيل فحص محلي مجاني بالصيغتين والمعدلين عبر الأمر التالي. اختر مجلدًا جديدًا لتجنب استبدال ملفات سابقة.

```bash
node scripts/check-director-production.mjs output/production-check
```

توليد الوسائط اختياري ويتطلب تأكيدًا داخل الأداة. يعرض Studio حد الطلبات وتقدير سينما Omni وفق الإعدادات الحالية. راجع [حالة التطوير](../DEVELOPMENT_CLOSURE.md) قبل استعمال التوليد الحقيقي.
