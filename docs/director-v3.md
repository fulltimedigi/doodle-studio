# Director V3 — experimental slice

Independent local-only editor; existing Doodle and Reel Pro remain untouched. Six distinct schematic compositions, editable timeline, local image/video per scene, Arabic text fitting, 1080 portrait/landscape, PNG and real-time video export (browser-dependent MP4 or WebM). The same renderer drives preview and recording. The sample uses no fabricated sales metrics. No synthetic pen noise, provider calls or remote media.

Limitations: artwork is procedural and schematic, not AI-generated; user supplies bespoke images, screen recordings and a single narration audio track. No automatic TTS, music, beat alignment or creative AI director yet. JSON saves text/timing only. Quality checks are heuristic; duplicate assets use filename/size/mtime. Export requires a visible supported browser and real codec/A-V verification. Max 30 scenes, 600 seconds.

Before release: run node --test test/director-v3.test.mjs, npm test, npm run build:site locally; manually test Arabic layout, both aspect ratios, video attachments and export playback. No cloud CI or provider spend without approval.

## Slice 2: optional AI director and narration

The separate module director-ai.js supports structured scene planning with concrete visual directions, unique prompts, optional image generation per scene or missing-art batch, and narration generated per scene. An actual recording is required for media/evidence scenes. Generated images are labelled illustrative; only generated artwork is cropped and moved. Uploaded screen recordings stay contained. Audio is decoded locally to 24 kHz, padded per scene, assembled into a single WAV, and scene lengths are adjusted to measured samples. Editing narration/timing/order after generation blocks export until re-synchronized or removed. Cache is per session; project JSON preserves creative directions but not binary assets.

Every provider operation requires an explicit request-count confirmation, uses a single selected model with no retries or fallback, and respects the per-operation count cap. This does not cap the provider's bill, and model availability and actual charges must be verified by the operator. No provider call is needed for manual mode. No remote screenshot upload. Existing stored key can be used; this page does not persist changes to keys. No automatic soundtrack or character-reference conditioning yet. No real API or browser playback verification in this slice; run local tests, browser checks, and only an explicitly authorized small provider pilot before release.


## Slice 3 — continuity, cinematic layout and local mastering
Character description persists in JSON; optional uploaded reference is session-only and is included only for selected scenes and explicit generation approval. References guide identity, not guarantee consistency. Hero artwork has full-bleed composition, controlled camera drift, contrast gradient and editable Arabic text; actual product evidence still requires non-generated media. Quality review flags repeated visual descriptions and blocks AI artwork in proof scenes.
Music is user-supplied with rights, locally decoded and looped with soft edges, normalized, ducked according to speech energy, faded, and peak-limited. A single cached mixed track serves preview/video/WAV. No external music generation. No actual API request or browser rendering tested; browser and full local suite remain release gates.

## Slice 4 — browser findings and correction
A checksum-matched copy of slice 3's actual renderer was tested in local Chromium: 12 sample compositions (six each aspect ratio) and two illustrative hero test frames returned valid title/subtitle fit. A 12-second real MediaRecorder capture encoded 1920×1080 VP9-in-MP4. The system Arabic fallback font was used because the repository font could not be downloaded to that isolated runner. The visual review found schematic repeated product dots, excess space, RTL step direction and ambiguous MP4 codec. Slice 4 changes product silhouettes, framing, RTL ordering, image pan overscan, art label fit reporting and explicit H.264/AAC preference with WebM fallback; no arbitrary MP4. The local smoke script can verify bundled Cairo and the actual browser encoder in a complete checkout. Full editor UI, audio/video synchronization, provider outputs and release build remain unverified.
